# LAZAREV. Website Clone

demo:- lazarevwebsite.vercel.app

A frontend **clone of the LAZAREV. website**, created for educational and practice purposes. This project recreates the original website's visual design, layout, animations, smooth scrolling, interactive elements, and overall user experience using HTML, CSS, and JavaScript.

## 📌 About The Project

This is a **clone/recreation of the LAZAREV. digital product design agency website**.

The main goal of this project was to practice modern frontend development and recreate a high-quality agency website with interactive animations and smooth user interactions.

The project includes:

- Modern agency-style UI
- Smooth scrolling
- GSAP animations
- ScrollTrigger animations
- Interactive hover effects
- Video sections
- Responsive layout
- Dynamic UI interactions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- Locomotive Scroll
- Remix Icons
- Vercel

## ⚠️ Disclaimer

This project is **not the official LAZAREV. website** and is not affiliated with or endorsed by LAZAREV.

It is a **frontend clone created solely for educational and learning purposes** to practice website development, animations, UI/UX, and modern frontend techniques.
